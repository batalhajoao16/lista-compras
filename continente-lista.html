ID da Folha
Chave API Google
📋 Estrutura do Google Sheets
Cria uma folha com duas abas com estes nomes exatos:
Aba "Produtos"
Coluna A → Nome do produto
Coluna B → Número do corredor

Aba "Lista"
Coluna A → Nome do produto
Coluna B → Comprado (TRUE/FALSE)
🗑 Limpar lista
Remove todos os produtos da lista atual. A base de dados de produtos (corredores) não é apagada.
